# SAN3TY — Smart Home Services Platform

A responsive Arabic RTL website concept for SAN3TY, a smart home-maintenance services platform for the Egyptian market.

## Run locally
Open `index.html` in a browser. No build step or framework is required. The page loads Cairo/Alexandria fonts from Google Fonts when internet access is available.

## Files
- `index.html` — website structure and Arabic content
- `styles.css` — responsive visual design, animations, and mobile layout
- `script.js` — mobile navigation, scroll reveals, and interactive demo chat

## Included sections
Problem, six-step customer journey, interactive demo for plumbing/electrical/air-conditioning requests, smart matching criteria, value proposition, revenue model, and risk management.

## Prototype limitations
The chat is a front-end demonstration only. It is not connected to an AI model, real technicians, booking, payment, or a database. Image attachments are previewed locally in the browser and are not uploaded or analyzed. Production functionality requires a backend, database, real technician records, and an AI service.

The content follows the SAN3TY business plan supplied for the project.
